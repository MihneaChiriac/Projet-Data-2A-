# Projet-Data-2A-

liens importants :

### Eleve 1 :

* **Commerces de bouche &amp; Restaurants (Base SIRENE)**
  * **Lien** : [data.gouv.fr - Base SIRENE des entreprises](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Fwww.data.gouv.fr%2Ffr%2Fdatasets%2Fbase-sirene-des-entreprises-et-de-leurs-etablissements-siren-siret%2F)
  * **Usage** : Filtrer par codes NAF/APE pour obtenir l'emplacement de tous les fast-foods, boulangeries et supermarchés à Paris.
* **Données géographiques OpenStreetMap (Poubelles, Parcs, Bâtiments)**
  * **Lien** : [API Overpass (OpenStreetMap)](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Foverpass-api.de%2F) / [Documentation de la bibliothèque Python OSMnx](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Fosmnx.readthedocs.io%2F)
  * **Usage** : Extraire les objets spatiaux (poubelles, parcs, équipements) directement en Python via des requêtes Overpass.
* **Marchés alimentaires découverts**
  * **Lien** : [Paris Data - Marchés découverts](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Fopendata.paris.fr%2Fexplore%2Fdataset%2Fmarches-decouverts%2F)
  * **Usage** : Récupérer la localisation, les jours et les horaires des marchés en plein air.
* **Chantiers de voirie et perturbations**
  * **Lien** : [Paris Data - Chantiers perturbants](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Fopendata.paris.fr%2Fexplore%2Fdataset%2Fchantiers-perturbants%2F)
  * **Usage** : Identifier les travaux de voirie et de terrassement qui déplacent les rongeurs.
* **Mobilier de propreté &amp; Corbeilles de rue**
  * **Lien** : [Paris Data - Corbeilles de rue](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Fopendata.paris.fr%2Fexplore%2Fdataset%2Fcorbeilles-de-rue%2F)
  * **Usage** : Densité de conteneurs et corbeilles publiques par quartier.
* **Espaces verts, parcs et jardins**
  * **Lien** : [Paris Data - Espaces verts et assimilés](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Fopendata.paris.fr%2Fexplore%2Fdataset%2Fespaces%5Fverts%2F)
  * **Usage** : Surfaçage des parcs et squares fermés/ouverts à Paris.
 
### Eleve 2 : 

* **Signalements DansMaRue (Flux courant / récent)**
  * **Lien** : [Paris Data - Dans Ma Rue (Anomalies signalées)](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Fopendata.paris.fr%2Fexplore%2Fdataset%2Fdans-ma-rue%2F)
  * **Usage** : Données en direct et de l'année en cours (filtrer sur le type *Rongeurs*).
* **Signalements DansMaRue (Historique 2012 - 2024)**
  * **Lien** : [Paris Data - Dans Ma Rue Historique](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Fopendata.paris.fr%2Fexplore%2Fdataset%2Fdans-ma-rue-historique-anomalies-signalees%2F)
  * **Usage** : Fichiers CSV annuels pour construire un historique long.
* **Données Météo Historiques &amp; Précipitations (Gratuit &amp; sans clé d'API)**
  * **Lien** : [Open-Meteo API Historical Weather](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Fopen-meteo.com%2Ffr%2Fdocs%2Fhistorical-weather-api)
  * **Usage** : Interroger directement la météo passée à Paris (température, pluie cumulée, pluie la veille) par date.
* **Découpage géographique IRIS (IGN / Insee)**
  * **Lien** : [data.gouv.fr - Contours IRIS Insee/IGN](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Fwww.data.gouv.fr%2Ffr%2Fdatasets%2Fcontours-iris-insee-ign%2F)
  * **Usage** : Récupérer les contours géographiques au format GeoJSON/Shapefile des 1 000 quartiers IRIS de Paris.
* **Population &amp; Données Socio-Démographiques par IRIS (Insee Filosofi)**
  * **Lien** : [Insee - Structure et distribution des revenus (Filosofi)](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Fwww.insee.fr%2Ffr%2Fstatistiques%2F7704076)
  * **Usage** : Récupérer la population totale par IRIS pour calculer les taux de signalement pour 10 000 habitants.
